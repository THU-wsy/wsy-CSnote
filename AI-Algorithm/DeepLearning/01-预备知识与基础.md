## 1. 机器学习简介

时至今日，人们常用的计算机程序几乎都是软件开发人员从零编写的。比如，要编写一个程序来管理网上商城，就需要软件开发人员来根据业务逻辑、完善边界情况来实现。然而，假如开发人员要试图解决以下问题之一：

- 编写一个应用程序，接受自然文本表示的问题，并正确回答该问题；
- 编写一个应用程序，接受一张图像，识别出该图像所包含的人，并在每个人周围绘制轮廓；
- 编写一个应用程序，向用户推荐他们可能喜欢，但在自然浏览过程中不太可能遇到的产品；

在这些情况下，即使是顶级程序员也无法提出完美的解决方案。即使人类的眼睛能毫不费力地完成这些难以提出完美解决方案的任务，这其中的计算也超出了人类意识理解范畴。而机器学习（machine learning，ML）正是一类强大的可以从经验中学习的技术。通常采用观测数据或与环境交互的形式，机器学习算法会积累更多的经验，其性能也会逐步提高。

机器学习的**核心组件**：

1. **数据（Data）**：每个数据集由样本（example/sample）组成，通常独立同分布（i.i.d.）
2. **模型（Model）**：将输入转换为输出的映射函数，由参数决定
3. **目标函数（Objective Function）**：量化模型预测与真实值之间的差距（如损失函数）
4. **优化算法（Optimization Algorithm）**：调整模型参数以优化目标函数的算法（如 SGD）

监督学习（supervised learning）擅长在"给定输入特征"的情况下预测标签，所以监督学习需要向模型提供巨大数据集：每个样本包含特征和相应标签值。监督学习的主要类型有：

| 类型 | 描述 | 示例 |
|------|------|------|
| 回归 | 预测连续值 | 房价预测 |
| 分类 | 预测离散类别 | 图像分类 |
| 标记问题 | 预测多个标签 | 图像标注 |
| 搜索 | 排序结果 | 搜索引擎 |
| 推荐系统 | 个性化推荐 | 商品推荐 |
| 序列学习 | 处理序列输入/输出 | 机器翻译 |

**gather 按索引收集**

### 2.7 自动微分（Autograd）

深度学习框架通过自动计算导数，即自动微分（automatic differentiation）来加快求导。实际中，根据设计好的模型，系统会构建一个计算图（computational graph），来跟踪计算是哪些数据通过哪些操作组合起来产生输出。自动微分使系统能够随后反向传播梯度。这里，反向传播（backpropagate）意味着跟踪整个计算图，填充关于每个参数的偏导数。

**基本用法**

```python
# 创建需要梯度的张量
x = torch.arange(4.0, requires_grad=True)
# 等价于: x = torch.arange(4.0); x.requires_grad_(True)

# 前向计算
y = x @ x

# 反向传播求梯度（注意，必须是标量才能调用 backward）
y.backward()

# 获取梯度
x.grad  # tensor([0., 2., 4., 6.])

# 梯度清零（PyTorch 默认累积梯度，每轮迭代需清零）
x.grad.zero_()
# 也可以用优化器中的 optimizer.zero_grad()
```

**分离计算（detach）**

```python
x = torch.arange(4.0, requires_grad=True)
y = x * x
u = y.detach()   # 将某些计算移出计算图，u 与 y 的值相同，但没有梯度信息
z = u * x
z.sum().backward()
x.grad == u      # u 被视为常数
```

**上下文管理**

```python
# with 块内不追踪梯度
with torch.no_grad():       
    y = x * 2

# with 块内开启梯度追踪（一般不使用，因为正常情况下梯度追踪默认就是开启的）
with torch.enable_grad():   
    y = x * 2
```



## 3. 线性回归

### 3.1 核心概念

- **线性模型**：$\hat{y} = \mathbf{w}^\top \mathbf{x} + b$
- **损失函数**：均方误差 $L(\mathbf{w}, b) = \frac{1}{2n}\sum_{i=1}^n (\hat{y}_i - y_i)^2$
- **解析解**：$\mathbf{w}^*, b^* = \arg\min L$ 可通过正规方程求解
- **小批量随机梯度下降**（Minibatch SGD）：当数据量大时使用迭代优化

### 3.2 从零实现

```python
import torch
import random

# ---- 1. 生成数据集 ----
def synthetic_data(w, b, num_examples):
    """生成 y = Xw + b + 噪声"""
    X = torch.normal(0, 1, (num_examples, len(w)))
    y = torch.matmul(X, w) + b
    y += torch.normal(0, 0.01, y.shape)
    return X, y.reshape(-1, 1)

true_w = torch.tensor([2, -3.4])
true_b = 4.2
features, labels = synthetic_data(true_w, true_b, 1000)

# ---- 2. 读取数据集 ----
def data_iter(batch_size, features, labels):
    num_examples = len(features)
    indices = list(range(num_examples))
    random.shuffle(indices)
    for i in range(0, num_examples, batch_size):
        batch_indices = torch.tensor(indices[i: min(i + batch_size, num_examples)])
        yield features[batch_indices], labels[batch_indices]

# ---- 3. 初始化模型参数 ----
w = torch.normal(0, 0.01, size=(2, 1), requires_grad=True)
b = torch.zeros(1, requires_grad=True)

# ---- 4. 定义模型 ----
def linreg(X, w, b):
    """线性回归模型"""
    return torch.matmul(X, w) + b

# ---- 5. 定义损失函数 ----
def squared_loss(y_hat, y):
    """均方损失"""
    return (y_hat - y.reshape(y_hat.shape)) ** 2 / 2

# ---- 6. 定义优化算法 ----
def sgd(params, lr, batch_size):
    """小批量随机梯度下降"""
    with torch.no_grad():
        for param in params:
            param -= lr * param.grad / batch_size
            param.grad.zero_()

# ---- 7. 训练 ----
lr = 0.03
num_epochs = 3
batch_size = 10
net = linreg
loss = squared_loss

for epoch in range(num_epochs):
    for X, y in data_iter(batch_size, features, labels):
        l = loss(net(X, w, b), y)    # 前向传播 + 损失
        l.sum().backward()           # 反向传播
        sgd([w, b], lr, batch_size)  # 更新参数
    with torch.no_grad():
        train_l = loss(net(features, w, b), labels)
        print(f'epoch {epoch + 1}, loss {float(train_l.mean()):f}')
```

### 3.3 简洁实现

```python
import torch
from torch import nn
from torch.utils import data

# ---- 1. 生成数据集 ----
# 同从零实现，复用 synthetic_data

# ---- 2. 读取数据集 ----
def load_array(data_arrays, batch_size, is_train=True):
    """构造 PyTorch 数据迭代器"""
    dataset = data.TensorDataset(*data_arrays)
    return data.DataLoader(dataset, batch_size, shuffle=is_train)

batch_size = 10
data_iter = load_array((features, labels), batch_size)

# ---- 3. 定义模型 ----
net = nn.Sequential(nn.Linear(2, 1))

# ---- 4. 初始化模型参数 ----
def init_weights(m):
    if isinstance(m, nn.Linear):
        nn.init.kaiming_uniform_(m.weight)
        if m.bias is not None:
            nn.init.zeros_(m.bias)
net.apply(init_weights)

# ---- 5. 定义损失函数 ----
loss = nn.MSELoss()

# ---- 6. 定义优化器 ----
trainer = torch.optim.SGD(net.parameters(), lr=0.03)

# ---- 7. 训练 ----
num_epochs = 3
for epoch in range(num_epochs):
    net.train()
    for X, y in data_iter:
        trainer.zero_grad()
        l = loss(net(X), y)
        l.backward()
        trainer.step()
    net.eval()
    with torch.no_grad():
        l = loss(net(features), labels)
        print(f'epoch {epoch + 1}, loss {l:f}')
```



## 4. Softmax 回归

### 4.1 核心概念

- **网络架构**：全连接层，输出维度 = 类别数 $q$
- **Softmax 运算**：$\hat{y}_j = \frac{\exp(o_j)}{\sum_k \exp(o_k)}$
  - 将 logits 映射到概率空间 $(0, 1)$，且和为 1
- **交叉熵损失**：$H(y, \hat{y}) = -\sum_j y_j \log \hat{y}_j$
  - 对于 one-hot 标签：$H = -\log \hat{y}_y$（直接取正确类别的负对数概率）

### 4.2 从零实现

```python
import torch
import torchvision
from torch.utils import data
from torchvision import transforms

# ---- 1. 读取数据集 ----
def load_data_fashion_mnist(batch_size, resize=None):
    """下载Fashion-MNIST数据集，然后将其加载到内存中"""
    trans =[transforms.ToTensor()]
    if resize:
        trans.insert(0, transforms.Resize(resize))
    trans = transforms.Compose(trans)
    mnist_train = torchvision.datasets.FashionMNIST(root='./data', train=True, transform=trans, download=True)
    mnist_test = torchvision.datasets.FashionMNIST(root='./data', train=False, transform=trans, download=True)
    return (data.DataLoader(mnist_train, batch_size, shuffle=True, num_workers=4),
            data.DataLoader(mnist_test, batch_size, shuffle=False, num_workers=4))

batch_size = 256
train_iter, test_iter = load_data_fashion_mnist(batch_size)

# ---- 2. Softmax定义 ----
def softmax(X):
    """X形状为 (batch_size, num_features)"""
    X_exp = torch.exp(X)
    partition = X_exp.sum(dim=1, keepdim=True)
    return X_exp / partition  # 广播机制

# ---- 3. 初始化模型参数 ----
num_inputs = 28 * 28
num_outputs = 10
w = torch.normal(0, 0.01, size=(num_inputs, num_outputs), requires_grad=True)
b = torch.zeros(num_outputs, requires_grad=True)

# ---- 4. 定义模型 ----
def net(X):
    return softmax(torch.matmul(X.reshape(-1, w.shape[0]), w) + b)

# ---- 5. 交叉熵损失函数 ----
def cross_entropy(y_hat, y):
    return -torch.log(y_hat[range(len(y_hat)), y])

# ---- 6. 分类精度 ----
def accuracy(y_hat, y):
    """计算预测正确的数量"""
    if len(y_hat.shape) > 1 and y_hat.shape[1] > 1:
        y_hat = y_hat.argmax(axis=1)
    cmp = y_hat.type(y.dtype) == y
    return float(cmp.type(y.dtype).sum())

# ---- 7. 训练 ----
# 训练代码与线性回归类似，只是损失函数和模型不同
```

```python
        if m.bias is not None:
            nn.init.zeros_(m.bias)
net.apply(init_weights)

# 交叉熵损失：内部包含了 softmax 操作，所以模型的最后一层不要加 softmax
loss = nn.CrossEntropyLoss()

# 优化器
trainer = torch.optim.SGD(net.parameters(), lr=0.1)
```



## 5. 多层感知机（MLP）

### 5.1 核心概念

- **隐藏层**：在输入和输出之间增加一个或多个全连接层
- **激活函数**：引入非线性变换，使网络能拟合任意函数（通用近似定理）
- 结构：输入 → 隐藏层（+ 激活函数）→ 输出

### 5.2 常用激活函数

| 函数 | 公式 | 特点 | API |
|------|------|------|-----|
| **ReLU** | $\max(0, x)$ | 最常用，简单高效 | `F.relu(x)` |
| **Sigmoid** | $\frac{1}{1+e^{-x}}$ | 输出 (0,1)，易梯度消失 | `F.sigmoid(x)` |
| **Tanh** | $\frac{1-e^{-2x}}{1+e^{-2x}}$ | 输出 (-1,1)，比 sigmoid 好 | `F.tanh(x)` |

> 说明：上述 API 是作为函数调用的方式，需在 `forward` 中直接调用；也有对应网络层的使用方式，例如 `nn.ReLU()`，需放在 `__init__` 中定义。两者无本质区别，通常在一个项目中统一风格即可。

### 5.3 简洁实现

```python
net = nn.Sequential(
    nn.Flatten(),
    nn.Linear(784, 256),
    nn.ReLU(),
    nn.Linear(256, 10)
)
```



## 6. 模型正则化

### 6.1 核心概念

| 概念 | 定义 |
|------|------|
| **训练误差** | 模型在训练集上的误差 |
| **泛化误差** | 模型在测试集上的误差 |
| **欠拟合** | 训练误差和泛化误差都很高（模型太简单） |
| **过拟合** | 训练误差很低，泛化误差很高（模型太复杂/数据太少） |

因此，我们要选择合适复杂度的模型。原则上，在我们确定所有的超参数之前，我们不希望用到测试集。如果我们在模型选择过程中使用测试数据，可能会有过拟合测试数据的风险，那就麻烦大了。如果我们过拟合了训练数据，还可以在测试数据上的评估来判断过拟合。但是如果我们过拟合了测试数据，我们又该怎么知道呢？

因此，我们决不能依靠测试数据进行模型选择。然而，我们也不能仅仅依靠训练数据来选择模型，因为我们无法估计训练数据的泛化误差。所以，我们通常会从训练数据中划分一部分作为验证集，它不参与模型训练，而是用来评估泛化误差。

### 6.2 权重衰减

在训练数据有限的前提下，为缓解过拟合，可以使用一些正则化模型的技术。权重衰减（weight decay）是广泛使用的正则化技术之一，也被称为 L2 正则化。

**原理**

在损失函数中加入权重的 $L_2$ 范数惩罚项：$$L(\mathbf{w}, b) + \frac{\lambda}{2} \|\mathbf{w}\|^2$$

- $\lambda$ 为正则化超参数
- 从而限制模型参数的大小，防止过拟合

**实现**

```python
# 通过优化器的 weight_decay 参数实现
trainer = torch.optim.SGD([
    {"params": net[0].weight, "weight_decay": 0.003},
    {"params": net[0].bias}
], lr=0.1)

# 或统一设置（但默认会同时衰减权重和偏置，不推荐使用）
trainer = torch.optim.SGD(net.parameters(), lr=0.1, weight_decay=0.003)
```

> 注意：通常只对**权重 weight**做 weight decay，不对**偏置 bias**做。因为 bias 只是偏移量、不会导致过拟合；衰减 bias 会限制模型的表达能力，可能导致欠拟合。

**推荐用法**

- 需要衰减的：卷积层、全连接层的 weight
- 不需要衰减的：所有 bias + 所有 Norm 层的参数

```python
decay_params = []
no_decay_params = []

for name, param in net.named_parameters():
    if not param.requires_grad:
          continue
    if 'bias' in name or 'norm' in name.lower():
        no_decay_params.append(param)
    else:
        decay_params.append(param)

optimizer = torch.optim.SGD([
    {'params': decay_params,    'weight_decay': 0.003},
    {'params': no_decay_params, 'weight_decay': 0.0},
], lr=0.1)
```

### 6.3 Dropout

**原理**

在训练时随机将隐藏层的一部分神经元输出置 0，减少对特定神经元的依赖，从而减少过拟合。

- 超参数：丢弃概率 $p$
- 训练时：$h' = \frac{h}{1-p} \odot \text{mask}$（mask 以概率 $1-p$ 为 1，否则 0），从而保证期望值不变
- 测试时：不做 dropout，保持所有神经元活跃

**从零实现**

```python
def dropout_layer(X, dropout):
    """dropout 层"""
    assert 0 <= dropout <= 1
    if dropout == 1:
        return torch.zeros_like(X)
    if dropout == 0:
        return X
    mask = (torch.rand(X.shape) > dropout).float()
    return mask * X / (1.0 - dropout)
```

**简洁实现**

```python
net = nn.Sequential(
    nn.Flatten(),
    nn.Linear(784, 256),
    nn.ReLU(),
    nn.Dropout(0.5),
    nn.Linear(256, 10)
)
```

**推荐用法**

Dropout 层通常放在激活函数之后。对于小模型通常取 `p=0.5`；对于大模型（数据量大）通常不使用 Dropout，如果使用也建议用一个较低值 `p=0.1`



## 7. 数值稳定性

### 7.1 问题

- **梯度消失**：参数更新过小，在每次更新时几乎不会移动，导致模型无法学习。例如 sigmoid，其导数的最大值为 0.25，会发生梯度消失。
- **梯度爆炸**：参数更新过大，破坏了模型的稳定收敛。通常是由于权重初始化值过大，或者学习率过大导致。
- **对称性问题**：如果所有参数初始化值相同，那么同一层的每个神经元会计算出完全相同的输出、接收到完全相同的梯度、进行完全相同的更新，从而一层的 N 个神经元退化成了 1 个神经元的 N 份拷贝，于是无法实现网络的表达能力。因此，参数需要进行随机初始化。

### 7.2 权重初始化

为保证数值稳定性，我们需要做较好的权重初始化。目标是尽可能保证：`每层输出的方差 = 输入方差`（前向稳定），同时`每层梯度的方差 = 下一层梯度的方差`（反向稳定）。常用的初始化方式有 **Xavier 初始化**和 **Kaiming 初始化**，这两个初始化方法的主要区别在于：**假设的激活函数不同**。

#### Xavier 初始化

适用于激活函数在 0 附近是线性的，如 sigmoid、tanh。Xavier 初始化从均值为 0，方差为 $\frac{2}{n_{in}+n_{out}}$ 的高斯分布/均匀分布中采样权重。其中 $n_{in}$ 是输入神经元个数，$n_{out}$ 是输出神经元个数。

```python
nn.init.xavier_normal_(m.weight)    # Xavier 正态分布
nn.init.xavier_uniform_(m.weight)   # Xavier 均匀分布
```

#### Kaiming 初始化

适用于 ReLU 族激活函数。Kaiming 初始化从均值为0，方差为 $\frac{2}{n_{in}}$ 的高斯分布/均匀分布中采样权重。

```python
nn.init.kaiming_normal_(m.weight)   # Kaiming 正态分布
nn.init.kaiming_uniform_(m.weight)  # Kaiming 均匀分布
```

> 说明：PyTorch 默认使用 `kaiming_uniform_` 进行权重初始化，而偏置默认是用一个很小的均匀分布进行初始化的（几乎接近 0）



## 8. PyTorch 深度学习 API

### 8.1 层和块

PyTorch 中一切皆 **Module**（块），`nn.Module` 是整个框架的基石。块可以描述单个层、由多个层组成的组件或整个模型本身。

#### 自定义块

```python
import torch
from torch import nn
from torch.nn import functional as F

class MyBlock(nn.Module):
    def __init__(self):
        # 必须调用父类 __init__
        super().__init__()
        # 定义各个网络层
        self.hidden = nn.Linear(20, 256)
        self.out = nn.Linear(256, 10)
        # 也可以自定义需要学习的参数，用 nn.Parameter 管理，会被注册到 net.parameters() 中
        self.embed = nn.Parameter(torch.randn(10, 32))

    def forward(self, X):
        # 前向传播：定义从输入到输出的计算
        X = self.out(F.relu(self.hidden(X)))
        return X @ self.embed
```

使用：

```python
X = torch.rand(1000, 20)
net = MyBlock()
net(X)
```

**关键要点**：

- `__init__` 中定义模块/参数，这些会被自动追踪学习
- `forward` 中定义前向计算逻辑，`net(X)` 是 `net.__call__(X)` 的缩写，里面就会调用 `forward`
- 在 `forward` 中**不**可以创建新的可学习参数（只能用 `__init__` 中的），因为 `forward` 里定义的新参数并不会被自动注册到 `net.parameters()` 中，所以无法被 optimizer 追踪学习

#### Sequential 块

```python
# Sequential 块
net = nn.Sequential(
    nn.Linear(20, 256),
    nn.ReLU(),
    nn.Linear(256, 10)
)
```

### 8.2 参数管理

#### 参数访问

```python
# 访问指定层
net[0]          # Linear(in_features=20, out_features=256, bias=True)

# 查看所有参数（返回 OrderedDict）
net.state_dict()

# 按层访问参数

```

> 注意：named_parameters() 是给**训练过程**用的，只包含可学习参数；state_dict() 是给**模型保存/加载**用的，既包含可学习参数、还包含 buffers（例如 BatchNorm 的 running_mean）

#### 参数初始化

通过 apply 进行参数初始化：

```python
def init_weights(m):
    if isinstance(m, (nn.Linear, nn.Conv2d)):
        nn.init.kaiming_uniform_(m.weight)
        if m.bias is not None:
            nn.init.zeros_(m.bias)
net.apply(init_weights)
```

常用内置初始化函数：

```python
nn.init.normal_(tensor, mean=0, std=1)        # 正态分布
nn.init.uniform_(tensor, a=0, b=1)            # 均匀分布
nn.init.constant_(tensor, val=0)              # 常量
nn.init.zeros_(tensor)                        # 零
nn.init.ones_(tensor)                         # 一
nn.init.xavier_uniform_(tensor)               # Xavier 均匀
nn.init.xavier_normal_(tensor)                # Xavier 正态

```

#### 共享权重（参数绑定）

两个层共享同一份权重，梯度会在绑定参数间累积

```python
class MiniGPT(nn.Module):
    def __init__(self, vocab_size, d_model):
        super().__init__()
        self.embed = nn.Embedding(vocab_size, d_model)
        self.lm_head = nn.Linear(d_model, vocab_size, bias=False)
        # 绑定：输出投影 = 输入嵌入
        self.lm_head.weight = self.embed.weight

    def forward(self, ids):
        x = self.embed(ids)
        return self.lm_head(x)

mini = MiniGPT(vocab_size=1000, d_model=64)
print(mini.embed.weight is mini.lm_head.weight)  # True
```

### 8.3 模型保存与加载

**保存/加载张量**：

```python
x = torch.tensor([1, 2])
y = torch.tensor([3, 4, 5])

# 保存张量
torch.save(x, 'single-tensor.pth')
torch.save([x, y], 'tensor-list.pth')

```

> 说明：`weights_only` 是安全性开关，True 限制 torch.load 只能还原安全的数据类型（如 Tensor 等），不会执行任意 Python 代码，免除恶意代码攻击的风险。

**保存/加载模型参数（推荐）**：

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class MLP(nn.Module):
    def __init__(self):
        super().__init__()
        self.hidden = nn.Linear(10, 32)
        self.out = nn.Linear(32, 2)

    def forward(self, x):
        return self.out(torch.relu(self.hidden(x)))

model = MLP()
optimizer = torch.optim.SGD(model.parameters(), lr=0.01)

for epoch in range(3):
    X = torch.randn(64, 10)
    y = torch.randint(0, 2, (64,))
    optimizer.zero_grad()
    loss = F.cross_entropy(model(X), y)
    loss.backward()
    optimizer.step()

# 只保存参数
torch.save(model.state_dict(), 'model.pth')

# 加载模型参数
loaded_model = MLP()
loaded_model.load_state_dict(torch.load('model.pth', weights_only=True))
loaded_model.eval()
```

**保存/加载完整模型（不推荐，有安全问题）**：

```python
# 保存完整模型
torch.save(model, 'model_full.pth')

# 要加载完整模型，只能设置 weights_only=False，有安全风险
loaded_full = torch.load('model_full.pth', weights_only=False)
loaded_full.eval()
```

**保存/加载 checkpoint**（含优化器状态，用于恢复训练）：

```python
# 保存 checkpoint
last_epoch = 2
torch.save({
    'epoch': last_epoch,
    'model_state_dict': model.state_dict(),
    'optimizer_state_dict': optimizer.state_dict(),
    'loss': 0.47,
}, 'checkpoint.pth')

# 加载 checkpoint 继续训练
checkpoint = torch.load('checkpoint.pth', weights_only=True)
restored_model = MLP()
restored_model.load_state_dict(checkpoint['model_state_dict'])

restored_optimizer = torch.optim.SGD(restored_model.parameters(), lr=0.01)
restored_optimizer.load_state_dict(checkpoint['optimizer_state_dict'])

start_epoch = checkpoint['epoch'] + 1
restored_model.train()  # 恢复训练模式

for epoch in range(start_epoch, start_epoch + 1):
    X = torch.randn(64, 10)
    y = torch.randint(0, 2, (64,))
    restored_optimizer.zero_grad()
    loss = F.cross_entropy(restored_model(X), y)
    loss.backward()
    restored_optimizer.step()
```
