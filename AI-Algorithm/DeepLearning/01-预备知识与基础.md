## 1. 机器学习简介

时至今日，人们常用的计算机程序几乎都是软件开发人员从零编写的。比如，要编写一个程序来管理网上商城，就需要软件开发人员来根据业务逻辑、完善边界情况来实现。然而，假如开发人员要试图解决以下问题之一：

- 编写一个应用程序，接受自然文本表示的问题，并正确回答该问题；
- 编写一个应用程序，接受一张图像，识别出该图像所包含的人，并在每个人周围绘制轮廓；
- 编写一个应用程序，向用户推荐他们可能喜欢，但在自然浏览过程中不太可能遇到的产品；

在这些情况下，即使是顶级程序员也无法提出完美的解决方案。即使人类的眼睛能毫不费力地完成这些难以提出完美解决方案的任务，这其中的计算也超出了人类意识理解范畴。而机器学习（machine learning，ML）正是一类强大的可以从经验中学习的技术。通常采用观测数据或与环境交互的形式，机器学习算法会积累更多的经验，其性能也会逐步提高。

机器学习的**核心组件**：

1. **数据（Data）**：每个数据集由样本（example/sample）组成，通常独立同分布（i.i.d.）
2. **模型（Model）**：将输入转换为输出的映射函数，由参数决定
3. **目标函数（Objective Function）**：量化模型预测与真实值之间的差距（如损失函数）
4. **优化算法（Optimization Algorithm）**：调整模型参数以优化目标函数的算法（如 SGD）

监督学习（supervised learning）擅长在"给定输入特征"的情况下预测标签，所以监督学习需要向模型提供巨大数据集：每个样本包含特征和相应标签值。监督学习的主要类型有：

| 类型 | 描述 | 示例 |
|------|------|------|
| 回归 | 预测连续值 | 房价预测 |
| 分类 | 预测离散类别 | 图像分类 |
| 标记问题 | 预测多个标签 | 图像标注 |
| 搜索 | 排序结果 | 搜索引擎 |
| 推荐系统 | 个性化推荐 | 商品推荐 |
| 序列学习 | 处理序列输入/输出 | 机器翻译 |

**gather 按索引收集**

沿着 dim，按 index 指定的位置去取值。注意，除 dim 维度外，index 的其他维度大小通常和 x 完全一致：

```python
index = torch.tensor([[0, 2], [1, 0]])

# 常见场景：分类任务取预测概率

probs = torch.gather(logits, dim=1, index=pred_labels)  # 取出每个样本对应类别的概率
```

**scatter_ 按索引写入**

### 2.6 广播机制（Broadcasting）

广播让形状不同的 tensor 也能进行逐元素运算，规则：

- 两个 tensor 的每个维度**从右往左**对齐，自动扩展以匹配

- 维度都大于 1 且不同则报错


### 2.7 自动微分（Autograd）

深度学习框架通过自动计算导数，即自动微分（automatic differentiation）来加快求导。实际中，根据设计好的模型，系统会构建一个计算图（computational graph），来跟踪计算是哪些数据通过哪些操作组合起来产生输出。自动微分使系统能够随后反向传播梯度。这里，反向传播（backpropagate）意味着跟踪整个计算图，填充关于每个参数的偏导数。

**基本用法**

```python
# 创建需要梯度的张量
x = torch.arange(4.0, requires_grad=True)
# 等价于: x = torch.arange(4.0); x.requires_grad_(True)

# 前向计算
y = x @ x

# 反向传播求梯度（注意，必须是标量才能调用 backward）
y.backward()

# 获取梯度
x.grad  # tensor([0., 2., 4., 6.])

# 梯度清零（PyTorch 默认累积梯度，每轮迭代需清零）
x.grad.zero_()
# 也可以用优化器中的 optimizer.zero_grad()
```

**分离计算（detach）**

```python
x = torch.arange(4.0, requires_grad=True)
y = x * x
u = y.detach()   # 将某些计算移出计算图，u 与 y 的值相同，但没有梯度信息
z = u * x
z.sum().backward()
x.grad == u      # u 被视为常数
```

**上下文管理**

```python
# with 块内不追踪梯度
with torch.no_grad():       
    y = x * 2

# with 块内开启梯度追踪（一般不使用，因为正常情况下梯度追踪默认就是开启的）
with torch.enable_grad():   
    y = x * 2
```



## 3. 线性回归

### 3.1 核心概念

- **线性模型**：$\hat{y} = \mathbf{w}^\top \mathbf{x} + b$
- **损失函数**：均方误差 $L(\mathbf{w}, b) = \frac{1}{2n}\sum_{i=1}^n (\hat{y}_i - y_i)^2$
- **解析解**：$\mathbf{w}^*, b^* = \arg\min L$ 可通过正规方程求解
- **小批量随机梯度下降**（Minibatch SGD）：当数据量大时使用迭代优化

### 3.2 从零实现

```python
import torch
import random

# ---- 1. 生成数据集 ----
def synthetic_data(w, b, num_examples):
    """生成 y = Xw + b + 噪声"""
    X = torch.normal(0, 1, (num_examples, len(w)))
    y = torch.matmul(X, w) + b
    y += torch.normal(0, 0.01, y.shape)
    return X, y.reshape((-1, 1))

true_w = torch.tensor([2, -3.4])
true_b = 4.2
features, labels = synthetic_data(true_w, true_b, 1000)

# ---- 2. 读取数据集 ----
def data_iter(batch_size, features, labels):
    num_examples = len(features)
    indices = list(range(num_examples))
    random.shuffle(indices)
    for i in range(0, num_examples, batch_size):
        batch_indices = torch.tensor(indices[i: min(i + batch_size, num_examples)])
        yield features[batch_indices], labels[batch_indices]

# ---- 3. 初始化模型参数 ----
w = torch.normal(0, 0.01, size=(2, 1), requires_grad=True)
b = torch.zeros(1, requires_grad=True)

# ---- 4. 定义模型 ----
def linreg(X, w, b):
    """线性回归模型"""
    return torch.matmul(X, w) + b

# ---- 5. 定义损失函数 ----
def squared_loss(y_hat, y):
    """均方损失"""
    return (y_hat - y.reshape(y_hat.shape)) ** 2 / 2

# ---- 6. 定义优化算法 ----
def sgd(params, lr, batch_size):
    """小批量随机梯度下降"""
    with torch.no_grad():
        for param in params:
            param -= lr * param.grad / batch_size
            param.grad.zero_()

# ---- 7. 训练 ----
lr = 0.03
num_epochs = 3
batch_size = 10
net = linreg
loss = squared_loss

for epoch in range(num_epochs):
    for X, y in data_iter(batch_size, features, labels):
        l = loss(net(X, w, b), y)    # 前向传播 + 损失
        l.sum().backward()           # 反向传播
        sgd([w, b], lr, batch_size)  # 更新参数
    with torch.no_grad():
        train_l = loss(net(features, w, b), labels)
        print(f'epoch {epoch + 1}, loss {float(train_l.mean()):f}')
```

### 3.3 简洁实现

```python
import torch
from torch import nn
from torch.utils import data

# ---- 1. 生成数据集 ----
# 同从零实现，复用 synthetic_data

# ---- 2. 读取数据集 ----
def load_array(data_arrays, batch_size, is_train=True):
    """构造 PyTorch 数据迭代器"""
    dataset = data.TensorDataset(*data_arrays)
    return data.DataLoader(dataset, batch_size, shuffle=is_train)

batch_size = 10
data_iter = load_array((features, labels), batch_size)

# ---- 3. 定义模型 ----
net = nn.Sequential(nn.Linear(2, 1))

# ---- 4. 初始化模型参数 ----
net[0].weight.data.normal_(0, 0.01)
net[0].bias.data.fill_(0)

# ---- 5. 定义损失函数 ----
loss = nn.MSELoss()

# ---- 6. 定义优化器 ----
trainer = torch.optim.SGD(net.parameters(), lr=0.03)

# ---- 7. 训练 ----
num_epochs = 3
for epoch in range(num_epochs):
    for X, y in data_iter:
        l = loss(net(X), y)
        trainer.zero_grad()
        l.backward()
        trainer.step()
    l = loss(net(features), labels)
    print(f'epoch {epoch + 1}, loss {l:f}')
```

## 八、Softmax 回归（多分类）

### 8.1 核心概念

- **网络架构**：全连接层，输出维度 = 类别数 $q$
- **Softmax 运算**：$\hat{y}_j = \frac{\exp(o_j)}{\sum_k \exp(o_k)}$
  - 将 logits 映射到概率空间 $(0, 1)$，且和为 1
- **交叉熵损失**：$H(y, \hat{y}) = -\sum_j y_j \log \hat{y}_j$
  - 对于 one-hot 标签：$H = -\log \hat{y}_y$（直接取正确类别的负对数概率）

### 8.2 信息论视角

- **熵**：$H(X) = -\sum p(x) \log p(x)$
- **信息量**：$I(x) = -\log p(x)$
- **交叉熵**：$H(P, Q) = -\sum P(x) \log Q(x) = H(P) + D_{KL}(P\|Q)$

### 8.3 从零实现

```python
# Softmax 定义
def softmax(X):
    X_exp = torch.exp(X)
    partition = X_exp.sum(1, keepdim=True)
    return X_exp / partition  # 广播机制

# 模型
def net(X):
    return softmax(torch.matmul(X.reshape((-1, W.shape[0])), W) + b)

# 交叉熵损失（从零实现）
def cross_entropy(y_hat, y):
    return -torch.log(y_hat[range(len(y_hat)), y])

# 分类精度
def accuracy(y_hat, y):
    """计算预测正确的数量"""
    if len(y_hat.shape) > 1 and y_hat.shape[1] > 1:
        y_hat = y_hat.argmax(axis=1)
    cmp = y_hat.type(y.dtype) == y
    return float(cmp.type(y.dtype).sum())

# 训练代码与线性回归类似，只是损失函数和模型不同
```

### 8.4 简洁实现

```python
import torch
from torch import nn

# 定义模型
net = nn.Sequential(nn.Flatten(), nn.Linear(784, 10))

# 初始化
def init_weights(m):
    if type(m) == nn.Linear:
        nn.init.normal_(m.weight, std=0.01)

net.apply(init_weights)

# 损失：自带 softmax 的交叉熵（注意：不做 softmax！）
loss = nn.CrossEntropyLoss()

# 优化器
trainer = torch.optim.SGD(net.parameters(), lr=0.1)
```

> ⚠️ **重要**：`nn.CrossEntropyLoss()` 内部包含了 softmax 操作，所以模型的最后一层**不要**加 softmax！

## 九、多层感知机（MLP）

### 9.1 核心概念

- **隐藏层**：在输入和输出之间增加一个或多个全连接层
- **激活函数**：引入非线性变换，使网络能拟合任意函数（通用近似定理）
- 结构：输入 → 隐藏层（+ 激活函数）→ 输出

### 9.2 常用激活函数

| 函数 | 公式 | 特点 | API |
|------|------|------|-----|
| **ReLU** | $\max(0, x)$ | 最常用，简单高效 | `nn.ReLU()` / `F.relu()` |
| **Sigmoid** | $\frac{1}{1+e^{-x}}$ | 输出 (0,1)，易梯度消失 | `torch.sigmoid()` |
| **Tanh** | $\frac{1-e^{-2x}}{1+e^{-2x}}$ | 输出 (-1,1)，比 sigmoid 好 | `torch.tanh()` |

```python
import torch.nn.functional as F

# ReLU
x = torch.arange(-5, 5, 0.1)
y = F.relu(x)

# Sigmoid
y = torch.sigmoid(x)

# Tanh
y = torch.tanh(x)
```

### 9.3 从零实现 MLP

```python
# 参数
num_inputs, num_outputs, num_hiddens = 784, 10, 256

W1 = nn.Parameter(torch.randn(num_inputs, num_hiddens, requires_grad=True) * 0.01)
b1 = nn.Parameter(torch.zeros(num_hiddens, requires_grad=True))
W2 = nn.Parameter(torch.randn(num_hiddens, num_outputs, requires_grad=True) * 0.01)
b2 = nn.Parameter(torch.zeros(num_outputs, requires_grad=True))
params = [W1, b1, W2, b2]

def relu(X):
    a = torch.zeros_like(X)
    return torch.max(X, a)

def net(X):
    X = X.reshape((-1, num_inputs))
    H = relu(torch.matmul(X, W1) + b1)
    return torch.matmul(H, W2) + b2
```

### 9.5 通用训练循环模板（重要！）

```python
def train_epoch(net, train_iter, loss, updater):
    """训练一个 epoch"""
    if isinstance(net, torch.nn.Module):
        net.train()
    metric = Accumulator(3)  # 训练损失 + 训练精度 + 样本数
    for X, y in train_iter:
        y_hat = net(X)
        l = loss(y_hat, y)
        if isinstance(updater, torch.optim.Optimizer):
            updater.zero_grad()
            l.mean().backward()
            updater.step()
        else:
            l.sum().backward()
            updater(X.shape[0])
        metric.add(float(l.sum()), accuracy(y_hat, y), y.numel())
    return metric[0]/metric[2], metric[1]/metric[2]
```

## 十、模型选择、欠拟合与过拟合

### 10.1 核心概念

| 概念 | 定义 |
|------|------|
| **训练误差** | 模型在训练集上的误差 |
| **泛化误差** | 模型在测试集上的误差 |
| **欠拟合** | 训练误差和泛化误差都很高（模型太简单） |
| **过拟合** | 训练误差很低，泛化误差很高（模型太复杂/数据太少） |
| **模型选择** | 选择合适复杂度的模型 |

### 10.2 验证方法

- **验证集**：从训练数据划分一部分用于模型选择，不参与最终训练
- **K 折交叉验证**：将数据分成 K 折，轮流用 K-1 折训练，1 折验证

### 10.3 多项式回归示例

## 十一、权重衰减（L2 正则化）

### 11.1 原理

在损失函数中加入权重的 $L_2$ 范数惩罚项：

$$L(\mathbf{w}, b) + \frac{\lambda}{2} \|\mathbf{w}\|^2$$

- $\lambda$ 为正则化超参数
- 限制模型参数的大小，防止过拟合
- 也叫 **岭回归（Ridge Regression）**

### 11.2 从零实现

```python
# 在训练循环中手动添加 L2 惩罚
def l2_penalty(w):
    return torch.sum(w.pow(2)) / 2

# 在损失计算时加上
l = loss(net(X), y) + lambd * l2_penalty(w)
```

### 11.3 简洁实现

```python
# 通过优化器的 weight_decay 参数实现
trainer = torch.optim.SGD([
    {"params": net[0].weight, 'weight_decay': 0.003},
    {"params": net[0].bias}], lr=0.1)

# 或统一设置
trainer = torch.optim.SGD(net.parameters(), lr=0.1, weight_decay=0.003)
```

> ⚠️ 通常只对**权重 weight**做 weight decay，不对**偏置 bias**做！

## 十二、暂退法（Dropout）

### 12.1 原理

在训练时随机将隐藏层的一部分神经元输出置 0，减少对特定神经元的依赖，从而减少过拟合。

- 丢弃概率 $p$（超参数）
- 训练时：$h' = \frac{h}{1-p} \odot \text{mask}$（mask 以概率 $1-p$ 为 1，否则 0）
- 测试时：不做 dropout，保持所有神经元活跃

### 12.2 从零实现

```python
def dropout_layer(X, dropout):
    """dropout 层"""
    assert 0 <= dropout <= 1
    if dropout == 1:
        return torch.zeros_like(X)
    if dropout == 0:
        return X
    mask = (torch.rand(X.shape) > dropout).float()
    return mask * X / (1.0 - dropout)
```

### 12.3 简洁实现

```python
net = nn.Sequential(
    nn.Flatten(),
    nn.Linear(784, 256),
    nn.ReLU(),
    nn.Dropout(0.5),   # 简洁！加一行即可
    nn.Linear(256, 256),
    nn.ReLU(),
    nn.Dropout(0.5),
    nn.Linear(256, 10)
)
```

## 十三、数值稳定性与初始化

### 13.1 问题

- **梯度消失**：sigmoid 饱和区梯度接近 0，深层网络无法训练
- **梯度爆炸**：参数过大导致梯度指数级增长
- **对称性问题**：如果所有参数初始化相同，隐藏层学到的表示也相同

### 13.2 Xavier 初始化（Glorot 初始化）

使每层的输入和输出方差保持一致：

```python
# PyTorch 默认初始化
nn.init.xavier_uniform_(m.weight)   # Xavier 均匀分布
nn.init.xavier_normal_(m.weight)    # Xavier 正态分布
nn.init.kaiming_uniform_(m.weight)  # He 初始化（适用于 ReLU）
nn.init.kaiming_normal_(m.weight)
```

```python
def get_k_fold_data(k, i, X, y):
    fold_size = X.shape[0] // k

    y_train = torch.cat([y[:val_start], y[val_end:]])
    X_val = X[val_start:val_end]
```
